# Day 02 - Tailwind CSS SBI NEFT Form

A simple **SBI Online NEFT Transfer Form** created using **HTML5 and Tailwind CSS**.

## 📌 Project Overview

This project is a frontend recreation of an online banking NEFT transfer form. It demonstrates how traditional CSS styling can be replaced with **Tailwind CSS utility classes**.

The form includes account selection, beneficiary selection, payment options, and transfer-related information.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- Responsive Design

## ✨ Features

- SBI Online NEFT Transfer interface
- Account selection
- Beneficiary account selection
- Purpose selection dropdown
- Payment option selection
- NEFT information notice
- Submit and Cancel buttons
- Tailwind CSS utility classes
- Simple and clean layout
