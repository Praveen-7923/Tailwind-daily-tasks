# Day-05-Tailwind-Portfolio

A clean and responsive personal portfolio website created using **HTML5 and Tailwind CSS**.

This project is part of my **Tailwind CSS Daily Tasks** series, where I practice building responsive web interfaces using Tailwind CSS utility classes.

## 📌 Project Overview

This portfolio website is designed to showcase my profile, skills, projects, and contact information in a simple and modern layout.

The website includes multiple sections with responsive design and hover effects using Tailwind CSS.

## ✨ Features

- Responsive navigation bar
- Hero section
- About Me section
- Skills section
- Featured Projects section
- Contact section
- Footer section
- Responsive design for mobile, tablet, and desktop
- Hover effects and smooth transitions
- Clean and modern UI
- Tailwind CSS utility classes
- No separate CSS file

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
