# Day 03 - Tailwind CSS Indusind Bank Credit Card Form

A simple **Indusind Bank Credit Card Payment Form** created using **HTML5 and Tailwind CSS**.

## 📌 Project Overview

This project is a frontend form designed to collect Indusind Bank credit card details and payment information.

The original form styling has been implemented using **Tailwind CSS utility classes**, without writing a separate CSS file.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- Responsive Web Design

## ✨ Features

- Indusind Bank header section
- Credit Card payment form
- Card type selection using radio buttons
- Credit card number fields
- Re-enter credit card number fields
- Email ID input
- Phone number input
- Payment amount input
- Bank account selection dropdown
- Submit button
- Tailwind CSS styling
- Clean and simple layout
